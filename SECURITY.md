# Security Policy

Do not open a public issue containing a credential, token, cookie, private URL, personal data, or
sensitive test artifact. Report suspected exposure through your organization's private security
channel and rotate affected credentials immediately.

For defects in this starter's code, use a private repository security advisory after the repository
is created on GitHub. For BrowserStack product concerns, use BrowserStack's official support and
security channels.

See [Security and compliance](docs/SECURITY_AND_COMPLIANCE.md) for operational controls.
